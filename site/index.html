What it does

  • Markdown viewer ⌘-click any .md file to read it rendered, beside the shell that printed it. Diagrams, links and live reload included. See how it works
  • Browser tabs with ad blocking ⌘-click a link and the page opens in a tab next to your terminal. Ads and trackers are blocked, built in. See how it works
  • Knows which terminal or agent needs you When an agent stops to ask, its tab, workspace, the menu bar and the Dock say so. One click takes you there, herdr agents included. See how it works
  • Workspaces, tabs and splits Projects down the side, each with its own tabs and splits. ⌘K reaches every command, and it all reopens on launch. See how it works
  • Native and secure SwiftUI and AppKit, drawn with Metal. Secure by default: output is treated as untrusted, so your clipboard and passwords stay yours. See how it works

Workspaces, tabs and splits

Terminals live in projects down the side, each with its own tabs. Switching swaps the whole working set; the shells left behind keep running.

Workspaces
A sidebar groups terminals into projects and shows which are busy, finished or waiting for you.
Splits and zoom
Split any tab, then zoom one pane to fill it with ⇧⌘↩.
Command palette
⌘K lists every menu command plus the links, paths, commit hashes and IP addresses on screen.
Comes back as you left it
Workspaces, tabs, splits and directories reopen on the next launch.

A Markdown viewer in every tab

⌘-click a README.md in ls output and it opens rendered, GitHub-style, in a tab next to the shell that printed it.

Live
Reloads as the file changes, so a plan or a README an agent is writing updates while you read it.
Diagrams
Mermaid diagrams are drawn in place.
Linked files
Links to other Markdown files open in new tabs, and ⌘[ ⌘] go back and forward.
Any file
⇧⌘M opens one from disk. Light by default, or matched to your terminal theme.

Browser tabs, with ad blocking built in

⌘-click a link in terminal output and the page opens in a Moo tab, in the same window and workspace, instead of sending you off to another app. Ads and trackers are blocked from the first page, with nothing to install.

Ad blocking
Built in and on by default: EasyList and AdGuard's base and tracking-protection lists, applied through WebKit's own content blocker. One switch in Settings › Links & Markdown turns it off.
A real browser
⇧⌘B new tab, ⌘L location, ⌘F find, ⌘[ ⌘] back and forward, ⌘+ zoom.
Sandboxed
Pages run sandboxed and are treated as hostile.
Your choice
⌥⌘-click opens the default browser instead.

Knows which terminal or agent needs you

Run a dozen agents across your projects and keep working. When one stops to ask, Moo says which one and where, and one click takes you to it.

Waiting for you
When an agent or any program asks for you (OSC 9, 777 or 99), its tab, its workspace, the menu bar bell and the Dock say so.
Straight to it
Click an entry in the bell or in Window › Notifications (⇧⌘U) and Moo opens the window, workspace, tab and split it came from.
Claude Code
Set Notifications to ghostty in Claude Code's /config and its requests land in Moo too.
herdr agents
Turn on Settings › Notifications › herdr, and every agent running in herdr inside a Moo tab shows up under its project in the sidebar, with its own status.
One entry per agent
Each agent is tracked on its own, so answering one never hides another's “needs you”. Entries are labeled as detected by herdr.
Read-only
Moo only reads herdr's status and focuses its panes. It never types into them.
Command status
A tab whose last command failed gets a red mark, and a long command finishing out of sight tells you it is done.
Your choice of alert
Banners, a Dock badge, a bounce, a sound or spoken words, each one optional. The list is always there.

Secure by default

A terminal shows whatever a program, a downloaded file or a remote host prints, and that text can try to read your clipboard, fake a prompt or launch something. Moo treats all of it as untrusted, so the safe choice is the one you get without changing a setting.

  • ClipboardReads refused, writes asked
  • PasswordsSecure Keyboard Entry at password prompts
  • LinksNothing runs from a click
  • UpdatesSigned, notarized, verified
Clipboard
Programs cannot read your clipboard, so a cat of a crafted file or a remote host cannot pull back a password you just pasted. Before a program writes to it, Moo asks, naming the pane and showing the text.
Secure Keyboard Entry
Turns on by itself at a password prompt, so other apps cannot watch what you type there, and off again when the prompt is gone.
Links
Web and mail links open directly; other kinds ask first. A link to anything that would run, such as an app or a script, is revealed in Finder, never launched.
Signed updates
Updates arrive through a signed feed, and each one is verified before it is installed.
Clean titles
Window titles, directories and names a program sets are cleaned of control and direction-changing characters, so output cannot write its own lines into a Moo dialog.
Shared profiles
Importing a .mooprofile keeps only its appearance unless you choose otherwise, after listing any shell, environment variables and key mappings it carries. It can never turn off a security setting.
Contained tabs
Markdown previews are hardened against hostile files, and browser tabs run sandboxed.
Security-reviewed
Features that touch the clipboard, links, shared files or other processes go through a dedicated security review before they ship, and the fixes are pinned by tests. The clipboard protection above came out of one of those reviews.
Native
SwiftUI and AppKit on SwiftTerm, drawn with Metal. Universal, signed and notarized.
