Moo Terminal

A native macOS terminal with Ghostty-class speed and the workspace features that make cmux good for running agents.

Download for macOS View on GitHub

Version 0.1.0 · universal (Apple silicon & Intel) · macOS 15+ · signed and notarized

What it does

  • Workspaces A sidebar groups terminals into projects, each with its own tabs. Switching swaps the whole working set; the shells left behind keep running.
  • Waiting for you When an agent asks for input, its tab, its workspace, the menu bar bell and the Dock say so. Click to land in that exact split.
  • Command status A tab whose last command failed gets a red mark, and a long command finishing out of sight tells you it is done.
  • Command palette ⌘K lists every menu command plus the links, paths, commit hashes and IP addresses on screen.
  • More than shells Markdown files open as rendered tabs and web pages as browser tabs with ad blocking, next to the terminal that printed them.
  • Safe by default Secure Keyboard Entry turns on by itself at password prompts, and links that would run something are revealed in Finder instead.
